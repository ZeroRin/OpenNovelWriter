## 准备输入

用户指定了提示词时使用该提示词，否则使用“预设-通用续写”。通过 `export_prompt` 按名称将用户库中的定义和依赖导出到当前会话 `artifacts/` 下的新目录，读取输入项、写作要求及输出格式。提示词须为场景续写类型，且已开启“允许 Agent 调用”。

`instruction` 描述这一段续写要发生什么。根据用户要求和相关细纲，整理参与人物、事件推进、关键转折、结束位置及必要的写作要求。例如：“萧景在城门与白冰儿重逢，试探来意后发现她身上有伤，决定带她离开。（通过对话表现戒备，暂不揭露伤势来源。）”模型选择、文件路径和检查附件等操作要求不写入其中。内容通过 `instruction.text` 提供给模板，提及的词条通过 `instruction.terms` 提供；是否输出由提示词决定。

用 `search_content` 按标题定位目标章节或场景，或从 `novel/outline.md` 获取标识，再读取对应章的正文投影，确定插入位置。`afterParagraph` 是插入点前方的一段唯一原文，用于划分提示词的前文和后文。接着场景末尾续写时，传入场景末尾的唯一原文；省略或传空字符串表示在场景开头写作，空场景也使用空值。这个参数只决定拼装上下文，不会自动决定最终写入位置。

按提示词输入名称填写 `inputs.custom`、`inputs.checkbox` 和 `inputs.contentSelection`。输入也可定义在导出的依赖组件中，无需在入口重复定义；同名时入口优先，组件之间按递归引用顺序取第一个。未指定的输入沿用默认值；显式传入的值替换该输入，不与默认值合并。仅模板及其 include 组件引用的必填输入需要补齐。

自定义输入传对象，例如 `inputs.custom["目标字数"] = { "dropdownOptionIds": ["导出定义中的选项ID"] }`，或 `{ "text": "2500" }`。从 `export_prompt` 导出的 `custom.dropdown.options` 读取选项 ID，由后端展开 `content`，为空时使用 `label`，不要传选项名称或自行复制选项内容。只能使用已启用的输入方式；单选下拉与自由文本二选一，多选允许组合。对象中省略的字段为空，`{}` 表示清空。复选框传布尔值，`false` 表示取消勾选；标记为必填的复选框必须勾选。

内容选择提供类型与 ID，遵循允许类型、词条类别及单选/多选设置，正文或摘要由输入配置决定；`[]` 表示清空。同一输入内重复引用会先按类型和标识去重，不影响其他输入选择同一份资料。

只有内容名称时，用 `search_content` 搜索并根据 `kind`、`context` 确认对象，将选中结果的 `target` 放入 `inputs.contentSelection[输入名称]` 数组。需要阅读材料时使用 `relativePath` 和 `anchor`；搜索结果不代表该提示词允许选取所有类型，仍须遵循输入配置。

## 生成正文

调用 `compose_scene_continuation`，将拼装消息写入当前会话 `artifacts/` 下的 `.md` 文件，读取返回的 `mdPath`、`missingInputs` 和 `groups`。缺少必填输入时先补齐再重新拼装；无法确定的值向用户询问。重新拼装会覆盖目标文件，需要保留已有生成版本或手动补充时使用新路径。本流程不创建续写面板。

沿用用户已明确的写作方式和模型组；尚未明确时，通过当前会话提供的 `request_user_input` 或 `request_user_input_async` 提问面板选择“由我直接写”或 `groups` 中的模型组，不默认使用第一个模型组。收到回答后继续生成，无需重复确认已有选择。

直接写作时读取拼装后的消息文件，按其中的写作要求生成并保存结果。用户要求子 agent 写作时，将消息文件路径、具体写作任务和结果文件路径交给子 agent，完成后读取结果。使用外部模型时，将消息文件的绝对路径和选定的 `groupId` 传给 `run_llm`；回复会追加为同一文件中的 `## assistant` 段。重新生成时保留提示词原有的示例消息，避免把上一版生成结果和无关的操作对话当作本次写作输入。

## 提交结果

检查生成内容后按用户要求展示或写入正文。展示 `run_llm` 的回复时使用返回的 `suggestedLink`，不在对话中重抄全文。

写入正文前读取 `edit-manuscript` 技能，按所用提示词的输出格式提取纯正文。内置续写预设取 `<Content>` 内部，不提交 `<Planning>`、标签或解释文字；`edit_scene_content` 不会自动拆分这些内容。需要整理时，用文件处理将正文保存为当前会话 `artifacts/` 下只有一个 `## assistant` 段的 MD；回复本身已是纯正文时可直接引用原文件。主 agent、子 agent 和外部模型的结果都通过 `source: { mdPath }` 提交，不在工具参数中重抄长文。

调用 `edit_scene_content` 时，空 `old_text` 只用于场景末尾追加或空场景起笔。写入场景开头或中间时，按最新正文中的唯一锚点做局部替换，并在替换内容中保留原有文字，使实际写入位置与拼装位置一致。
